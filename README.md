# 资本主义模组（Capitalism Mod）

一个以「现实经济」为目标的 Minecraft 模组：货币、银行、公司产业链、股票、债券、大宗商品现货与期货、拍卖、P2P 借贷、税务一应俱全，力求贴近真实金融体系。

> 基于 NeoForge 1.21.1。所有金额内部以「子单位」（分 / 美分 / 戈比，1 主单位 = 100 子单位）存储。

---

## 一、货币系统

- **4 种货币**：美元（USD）、人民币（CNY）、欧元（EUR）、卢布（RUB）。
- **子单位 + 现实面额**：既有纸币，也有硬币，面额按现实发行面值划分。
- **浮动汇率**：开服后自动联网抓取真实汇率（基准人民币，免 key），失败回退固定默认值。

## 二、银行系统

- **借记卡 / 信用卡**：19 位银联格式卡号（含 Luhn 校验位），空白卡到银行开户。
- **活期存款 / 定期存款 / 贷款 / 跨行转账 / 外汇兑换**：年化利率、期限、手续费、罚息俱全。
- **账单流水**：存取/贷款/还款/利息/转账/定期均有记录。
- **每日计息**：每个 Minecraft 日自动结算一次利息。

## 三、公司系统 + 产业链

- **20 个行业**：依据《国民经济行业分类》（GB/T 4754-2017/2023）门类 A–T。
- **工商局注册**：选行业、起名，领取营业执照。
- **完整产业链（数据驱动）**：公司不再是「各自独立产钱」，而是上下游投入产出依赖——
  - **上游原料**：采矿产铁锭/煤炭/金锭，农业产小麦。
  - **中游加工**：制造消耗铁锭+煤炭，产出成品（铁轨）。
  - **下游消费**：能源/交通消耗煤炭、建筑/房地产消耗铁轨、餐饮/医疗消耗小麦、零售消耗铁轨+小麦等。
  - **投入不足停产**：某行业原料在仓库不足时，该 tick 收入为 0、也不产出。
  - 投入产出表在 `config/capitalismmod/industries.json`，**可编辑注入其他模组物品**作为投入/产出。
- **仓储 = 公司原料库**：公司经营围绕「先把原料存入仓库」，产出也进仓库。
- **升级**：`/company upgrade` 提升等级，收益与产出随等级增长。

## 四、证券 / 股票

- **证监会上市（IPO）**：发行 `1000 × 等级` 股给创始人。
- **限价单订单簿**：挂单自动撮合、支持部分成交。
- **印花税 / 涨跌停 / 分红 / K 线行情**。

## 五、债券市场（国债）

- **低风险固定收益**：按面值购买国债（默认 $100，年化 5%，30 天到期），与股票/期货形成风险分层。
- **提前赎回**：按「面值 + 应计利息」卖回系统。
- **到期兑付**：到期自动兑付本金 + 全额利息（在线直发，离线进邮箱）。

## 六、大宗商品交易所（现货）

- **限价单订单簿**：挂单自动撮合、部分成交，统一美元计价。
- **实物交割 + 仓单**：卖单必须先从**仓库**入库，成交货进买方仓储，买方到仓库提货。
- **供需驱动价格 + 涨跌停 + K 线**：价格由「净成交量 + 公司生产/消耗的净供给」推动，向基本面回归，每日 ±10% 涨跌停。

## 七、期货交易所

- **保证金 / 杠杆**：开仓冻结名义价值 ×10%（`futuresMarginRate` 可调）。
- **多空双向**：开多 / 开空，现金结算，做空无需借货。
- **逐日盯市 + 强制平仓**：每天按结算价结算持仓盈亏；保证金余额 ≤0 的持仓被强平。
- **定期合约到期**：默认 7 天到期，到期现金结算并换月；期货价向现货价收敛（基差）。

## 八、仓库

- **全局交割仓库**：按玩家分仓储，商品存/取；同时是交易所交割库和公司原料库。

## 九、拍卖行

- **挂拍 → 出价 → 到期结算**：物品挂拍（仓储 escrow）、出价（被超出退款）、到期最高价者得物、无人出价退物。

## 十、玩家间金融

- **P2P 借贷**：`/lend` 放款、`/repay` 还款、`/loans` 查看，含利率与期限，逾期罚息双倍。
- **股权转让**：`/shares give` 场外直接转让持股（抽象股票 + 上市公司）。

## 十一、商店

- 用任意货币购买物品（默认配置：钻石、铁锭、绿宝石、金苹果等）。

## 十二、税务局

- **企业所得税**：公司收益自动按 25% 计提，到税务局缴纳。
- **发票**：商店购物自动获得发票，到税务局「报销」按 10% 退回现金。

## 十三、可玩性包装

- **财富榜**：`/ranking` 聚合钱包+银行+股票+商品+期货保证金，折美元排序。
- **经济新闻播报**：价格单次涨跌超 ±10%、大宗成交（>$10000）全服广播。

## 方块一览

| 方块 | 作用 |
|------|------|
| 商店 | 用货币购买物品 |
| 银行 | 开户、存取款、定期、贷款、转账、兑换、流水 |
| 工商局 | 注册公司、领取营业执照 |
| 仓库 | 商品存/取，交易所交割库 + 公司原料库 |
| 大宗商品交易所 | 商品现货挂单交易（实物交割、供需价格） |
| 期货交易所 | 商品期货（保证金、多空、盯市、强平、到期） |
| 证券交易所 | 股票挂单交易、行情 |
| 债券市场 | 国债购买、赎回、到期兑付 |
| 拍卖行 | 物品挂拍、竞拍 |
| 证监会 | 公司上市（IPO） |
| 税务局 | 缴税、发票报销 |

## 命令

| 命令 | 作用 |
|------|------|
| `/balance` | 查看各货币余额 |
| `/pay <玩家> <货币> <金额>` | 转账给玩家 |
| `/money <玩家> <货币> <金额>` | 管理员发放货币 |
| `/exchange <from> <to> <金额>` | 兑换货币 |
| `/fx` | 查看当前汇率 |
| `/company list / upgrade / withdraw` | 公司管理 |
| `/shares give <玩家> <股票> <数量>` | 场外转让持股 |
| `/lend <玩家> <货币> <金额> <天数> <利率%>` | 放贷给玩家 |
| `/repay <借据ID>` | 还款 |
| `/loans` | 查看我的借贷 |
| `/ranking` | 财富榜 |

## 配置（`config/capitalismmod-common.toml`）

| 配置项 | 默认 | 含义 |
|--------|------|------|
| `depositRatePerYear` | 0.05 | 活期存款年利率 |
| `loanRatePerYear` | 0.10 | 贷款年利率 |
| `termDepositRatePerYear` | 0.08 | 定期存款年利率 |
| `creditLimit` | 100000 | 信用额度（分，= 1000 元） |
| `incomeTaxRate` | 0.25 | 企业所得税率 |
| `invoiceRefundRate` | 0.10 | 发票报销比例 |
| `commodityPriceLimit` | 0.10 | 商品现货涨跌停幅度 |
| `futuresMarginRate` | 0.10 | 期货保证金率（= 10 倍杠杆） |
| `futuresExpiryDays` | 7 | 期货到期天数 |
| `bondFaceValue` | 100 | 国债面值（美元） |
| `bondRatePerYear` | 0.05 | 国债年利率 |
| `bondMaturityDays` | 30 | 国债到期天数 |

> 数据驱动配置（`config/capitalismmod/*.json`）：商店商品、大宗商品列表、抽象股票、**行业产业链投入产出表（可注入其他模组物品）**。

## 快速上手

1. 用调试棒或 `/money` 获取初始资金。
2. 摆**银行**开户，存钱、贷款。
3. 摆**工商局**注册公司（选行业、起名）。
4. 摆**仓库**，把生产原料存进去。
5. 让公司运转：采矿产矿石 → 存仓库 → 制造消耗矿石产成品 → 零售消耗成品赚钱。
6. 摆**证监会**把公司上市；摆**证券交易所**买卖股票；摆**债券市场**买国债。
7. 摆**大宗商品交易所**做现货、**期货交易所**做期货、**拍卖行**竞拍。
8. 摆**税务局**缴税、报销发票。
