# 股票、债券与期货系统开发进度

最后更新：2026-09-06

## 已实现功能

- 支持企业 IPO、股票发行、限价订单、撮合、股票持有和场外股份转让。
- 支持债券购买、持有、收益结算、提前赎回、到期兑付和持仓持久化。
- 支持期货多空仓位、保证金、每日盯市、手动平仓、强制平仓和到期结算。
- 支持股票、债券、期货的网络同步、市场界面、价格、K 线、订单和持仓数据。
- 状态变更会正确标记 `SavedData`；股票订单支持价格—时间优先和可配置有效期。
- 股票托管返还、债券兑付和期货结算均具备幂等账本或结算日标记。

## 存在的问题

- 证券发行审核、信息披露、估值、市场监管和投资者保护仍较简化。
- 分红、拆股、并股、停牌、退市、债券违约和公司行动尚未完整实现。
- 期货价格来源、保证金风险、追加保证金和跨市场联动仍需加强。
- 结算账本之间尚未具备跨文件原子事务。

## 后续方向

1. 完善证券生命周期、发行审核、披露和监管状态。
2. 增加分红、公司行动、债券违约和投资者权益处理。
3. 统一保证金、手续费、结算账户、风险检查和清算流程。
4. 建立稳定的价格形成、行情快照、历史数据和市场事件模型。
