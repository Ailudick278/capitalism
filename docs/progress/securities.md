# 证券与期货系统开发进度

## 已实现功能

- 债券发行先持久化发行意图，再确认买方付款；服务器中断后可依据稳定付款引用继续完成国库入账和债券持仓，避免付款与债券凭空分离。
- 同一公司同一结算日的同参数分红使用稳定批次编号；重复宣告不会再次扣减公司金库，只会恢复尚未完成的股东派付。

- 股票买单先保存买单意图并使用订单级付款引用，付款成功后先落盘订单再撮合；玩家登录时可恢复已付款但订单尚未写入的买单，避免资金悬挂。
- 股票卖单先保存卖单意图并托管持股，再落盘订单；玩家登录时可恢复持股已托管但订单尚未写入的卖单，成交后按订单 ID 更新剩余数量。
- 股票卖单意图同时记录扣除前持股快照；恢复时仅接受“未扣除”或“恰好扣除本单数量”两种明确状态，避免重复扣股。
- 股票成交量使用成交来源的一次性凭证，重复撮合不会重复影响价格统计；买卖成交引用均不再依赖会变化的对手订单数量。
- 成交量凭证已与持股收据分离并独立持久化，长期运行时不会因两类收据共用容量而互相淘汰。

- 支持股票、债券、期货、持仓、报价、保证金和到期结算。
- 股票买单到期释放未成交余额时使用订单 ID 幂等退款凭证，服务器重启不会重复返还资金。
- 股票卖单到期返还股份同样记录持久化凭证，订单删除前后重试不会重复增加持仓。
- 主动撤销股票订单时，托管股份或资金也使用订单级幂等凭证，避免撤单重试重复返还。
- 主动撤单只有在资金或股份返还凭证成功后才写入结算收据并删除订单；返还失败会保留订单，避免托管资产悬挂。
- 股票撮合成交向卖方支付时使用买卖订单、成交数量和金额组成的交易凭证，重复结算不会重复支付成交款。
- 股票成交的印花税税源复用同一成交凭证，不会因重试生成随机的新税源。
- 买单部分成交后的剩余资金退款绑定买单 ID，订单写入和退款重试不会重复返还。
- 股票订单到期返还资金或股份成功后才写入结算收据并删除订单；返还失败会保留订单，日结可以继续恢复托管。
- 股票成交增加买方持仓时复用成交凭证，成交重试不会重复增加股份。
- 股票撮合成交的股份记账、卖方到账和印花税现已写入统一金融结算日志，按成交凭证区分阶段。
- 股票撮合只有在卖家收款凭证成功后才提交订单减少和成交量更新；收款失败会保留订单，后续重试可继续完成成交。
- 期货手动平仓将保证金入账和净持仓调整拆成可恢复的阶段凭证，重复平仓不会重复计入收益或成交量。
- 期货每日盯市的盈亏和到期保证金返还按持仓 ID、结算日和阶段保存凭证，日结重试不会重复记账。
- 期货手动平仓会先保存入账前保证金余额意图，再应用保证金盈亏并写入阶段收据；中断恢复会识别已应用的入账，避免重复计入平仓收益或本金。
- 期货开仓会先保存持仓、保证金和净持仓量快照，再扣除保证金；登录和日结会恢复扣款后尚未完成的持仓，避免资金已锁定但头寸缺失。
- 期货强制平仓会同步回冲净未平仓量，并使用持仓级凭证避免重复调整市场成交量。
- 期货保证金提取使用玩家、提取前余额和金额组成的持久化凭证，保证金扣减后的钱包到账可安全重试。
- 股票分红先从企业资金池扣款，再按“企业、批次时间、每股金额、总额、股东”生成一次性到账凭证；在线和离线股东使用同一套邮箱结算，重启不会重复发放。
- 公开要约收购的股份转移在经济账本内使用要约级一次性凭证，卖方收款也通过同一要约的持久化到账凭证恢复。
- 期货保证金提现会先持久化提现前余额意图，再执行保证金扣减；重启时可判断扣减是否已发生，钱包到账失败会保留待处理记录，不会因余额变化重复扣减。
- 期货保证金入金会先持久化入金前余额意图，再执行钱包扣款和保证金增加；扣款或增加保证金后的中断可通过稳定支付来源恢复，不会重复扣款或重复入金。
- 债券到期票息使用高精度十进制定点计算，并按整币向下舍入，避免浮点误差改变偿付金额。
- 金融风险敞口估算复用债券实际偿付公式，风险比例与债券到期负债保持一致。
- 债券发行资金确认后会写入持久化发行批次，再按确定性持仓 ID 创建债券；日结会恢复资金已确认但持仓未完整生成的批次。
- 债券发行增加政府预算来源级凭证，发行批次恢复时不会重复增加财政收入。
- 债券发行在玩家扣款后立即保存支付确认；恢复流程可继续完成预算入账和持仓生成，旧发行记录保持兼容。
- 债券发行、提前兑付和到期兑付已接入统一金融结算日志，分别记录付款/财政资金、持仓生成或兑付到账阶段。
- 支持企业 IPO、股权基础结构和持久化交易记录。

## 存在的问题

- 企业财务报表、股东治理、信息披露和市场深度仍不完整。
- 分红批次的资金扣款、股东到账和分红税已接入统一金融结算日志，并保留原有逐笔收款恢复；完整的批次托管状态机仍需继续收敛。
- 公开要约现在写入付款、股份转移、卖方到账和税务四个托管阶段；若阶段间发生中断，重试不会重复扣款或转移，但买方钱包与股份账本仍尚未由统一托管事务原子提交。
- 股票逐笔成交现在保存成交意图和成交前订单数量，股份交割、卖方付款、印花税、成交量和订单更新均可在登录或日结时继续恢复；部分成交不会因重启重复减少订单。
- 期货价格与现货、库存、利率和风险预期的联动较弱。

## 后续方向

1. 接入统一企业资产负债表和现金流。
2. 增加股东投票、董事会、分红和并购。
3. 将股票、债券、期货的阶段日志进一步升级为统一托管协调器，覆盖资产、资金、税费和风险准备金的可恢复顺序。
4. 增加市场操纵、信息延迟和风险传导的约束。
