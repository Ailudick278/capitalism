# 证券与期货系统开发进度

## 已实现功能

- 股票同步包在服务端构造时复制价格、持仓、公司名称及每支股票的 K 线列表，阻止行情更新修改正在异步编码的数据；覆盖定时广播、打开交易所及操作后同步入口。集合快照回归测试覆盖编码遍历期间原列表清空/追加及快照不可变性。

- 支持股票、债券、期货的订单、持仓、成交和到期结算基础结构。
- 债券到期兑付会先记录政府扣款，再写入持久化持仓凭证，支持中断后重试。
- 证券与经济日结阶段相连，市场订单、到期兑付和风险指标可被统一审计。

## 存在的问题

- 证券价格仍主要由订单和规则驱动，尚未充分反映企业利润、利率、通胀和违约预期。
- 期货保证金、追加保证金和强制平仓的风险链路仍需完善。
- 玩家离线持仓索引和跨账户证券转移还没有统一托管账本。

## 后续方向

1. 将企业经营数据、政策利率和市场流动性接入估值与收益率曲线。
2. 建立保证金账户、每日盯市、追加保证金和强平结算闭环。
3. 统一证券托管、公司行动、违约处置和跨账本恢复凭证。
