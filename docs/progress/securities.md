# 债券日结与兑付幂等性（2026-09-06）

## 本次完成

- 每笔债券持仓新增 `lastSettlementDay`，债券到期天数按持仓独立结算。
- 新增到期兑付账本，记录已经完成兑付的债券持仓。
- 提前赎回也使用同一兑付账本，避免付款后持仓删除被中断时重复支付。
- 如果服务器在到期付款后、删除持仓前重启，下一次结算只清理残留持仓，不会重复付款。
- 旧存档缺失新字段时默认未结算，保持兼容。

## 现实逻辑对应

债券是独立的金融合同，期限递减和到期兑付应以每笔持仓为单位处理，而不是依赖全局循环一次性完成。本次修复使债券合同的到期状态和兑付记录更加接近现实金融结算。

# 期货手动平仓幂等性（2026-09-06）

## 本次完成

- 新增手动平仓结算账本。
- 平仓盈亏和保证金返还完成后，会记录持仓已结算状态，再删除持仓。
- 如果删除持仓前服务器中断，重试时只清理残留持仓，不会重复增加保证金。
- 账本限制记录数量，避免世界存档无限增长。

## 现实逻辑对应

期货平仓需要同时完成头寸关闭和盈亏结算；两者不能因为服务器中断而重复执行或只执行一半。本次为手动平仓增加了独立结算凭证。

# 期货每日盯市幂等性（2026-09-06）

## 本次完成

- 每个期货持仓新增 `lastSettlementDay`，同一持仓不会重复执行同一天的盯市盈亏结算。
- 期货日计数改为按经济结算日推进，重复调用同一天结算不会再次增加合约日数。
- Futures 全局结算日会持久化，正常重复调用会直接跳过。
- 旧存档缺失新字段时默认未结算，保持兼容。

## 现实逻辑对应

期货合约按交易日进行每日盯市（mark-to-market），每日盈亏进入保证金账户；同一交易日不能重复结算。本次修复使持仓、到期日和保证金变动与交易日边界保持一致。

### stock-order-escrow-idempotency-2026-09-06.md

# 股票订单托管返还幂等性（2026-09-06）

## 本次完成

- 新增股票订单托管返还账本。
- 股票订单撤单和过期释放现在先返还股票/资金，再记录结算，最后删除订单。
- 如果返还完成但订单删除被中断，重试时只清理残留订单，不会重复返还托管资产。
- 账本限制记录数量，避免长期运行的世界存档无限增长。

## 现实逻辑对应

限价订单的股票或资金在成交前属于托管资产；撤单或过期时应释放托管，而不是直接销毁。本次修复使股票订单的托管释放更符合交易所订单生命周期。
