# 股票、债券与期货系统开发进度

最后更新：2026-09-05

## 已实现功能

- 支持企业 IPO、股票订单、股票交易和场外股份转让基础结构。
- 支持债券发行/持有、购买、赎回、到期兑付和收益结算。
- 支持期货多空仓位、保证金、逐日盯市、强制平仓和到期结算。
- 支持股票、债券、期货数据保存、网络同步和相关市场界面。

## 当前边界与待处理问题

- 证券估值、发行审核、信息披露和市场监管仍然较简化。
- 股票分红、拆并股、停牌、退市和债券违约等事件还需要补充。
- 期货风险控制和价格来源需要与商品市场、现金账户更紧密地连接。

## 后续开发方向

1. 完善证券生命周期、发行规则和监管状态。
2. 增加分红、公司行动、债券违约和投资者权益处理。
3. 统一保证金、手续费、结算账户和风险检查。
4. 建立更稳定的价格形成、行情快照和历史数据模型。
