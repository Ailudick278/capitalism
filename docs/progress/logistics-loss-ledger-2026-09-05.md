# 物流损失记录与通知（2026-09-05）

## 本阶段已实现

- 未投保货物达到最大中断次数后，会写入持久化的物流损失台账，而不是静默删除。
- 台账记录货运编号、买方、物品、数量、起运地、目的地、运输方式、中断次数和损失时间。
- 玩家在线时立即收到损失通知；离线时会在下次登录后收到通知。
- 新增 `/logistics losses`，可以查看当前玩家最近的损失记录。
- 台账使用货运编号去重，并限制最多保存 4096 条，避免世界存档无限增长。

## 现实逻辑对应

运输合同中，货物灭失需要留下可审计的运输事故记录；是否赔付由保险状态决定。本阶段先把“损失事实”和“通知”独立记录，投保货物仍走保险赔付路径，未投保货物不自动返还货款或货物。

## 后续方向

- 将损失记录接入采购订单和企业成本，区分买方库存损失与卖方履约损失。
- 增加基于运输单据的索赔/理赔流程，而不是只依赖保险自动赔付。
- 按运输方式、基础设施和货物类型细化风险与免赔额。
