## 阶段路线（当前状态）

1. 基础稳定：已完成文档编码修复、经济主体与来源 ID 统一、资金边界检查、跨系统结算保护和回归测试。
2. 居民经济闭环：已完成 NPC 家庭持久化、收入、消费、就业、年龄队列和带成本迁移的基础闭环。
3. 合同与市场联动：已完成合同索引、物流交付、仓储、付款、损失和违约的可重试基础流程。
4. 城市与区域经济：已完成区域需求、公共设施、住房租金、维护成本和公共服务结算的基础闭环。
5. 政府与宏观经济：已完成税务、财政、政策利率、债券偿付、银行流动性和金融风险传导的基础闭环。
6. 结算可靠性：进行中。正在把资金托管、实体物品兑换、证券成交、批量分红、拍卖和供应订单统一到可恢复的结算日志；当前每日结算日志已具备不可回退的阶段状态，统一跨对象事务协调器仍未完成。

## 开发与验收规则

- 每个跨系统操作必须有稳定主体 ID、来源或请求 ID、币种、金额、时间和状态。
- 重复调用不得重复扣款、发放、计税、交付或增加负债。
- 持久化顺序必须允许重启后继续完成，或进入明确的退款、损失、违约或坏账状态。
- 新玩法必须同时提交实现、持久化、测试和对应系统日志；只写界面或只写内存状态不算完成。
- 经济参数应有现实含义和边界说明，但不直接复制现实国家的完整法律制度。
