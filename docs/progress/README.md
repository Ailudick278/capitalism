## 阶段路线（当前状态）

1. 基础稳定：已完成文档编码修复、经济主体与来源 ID 统一、资金边界检查、跨系统结算保护和回归测试。
2. 居民经济闭环：已完成 NPC 家庭持久化、收入、消费、就业、年龄队列和带成本迁移的基础闭环。
3. 合同与市场联动：已完成合同索引、物流交付、仓储、付款、损失和违约的可重试基础流程。
4. 城市与区域经济：已完成区域需求、公共设施、住房租金、维护成本和公共服务结算的基础闭环。
5. 政府与宏观经济：已完成税务、财政、政策利率、债券偿付、银行流动性和金融风险传导的基础闭环。
6. 结算可靠性：进行中。每日结算已按三个持久化阶段协调；恢复时会跳过已完成阶段，并通过金融交易日志追踪跨对象副作用。服务器级恢复协调器统一调度商品成交、证券成交、供应订单、期货、物流补偿、拍卖挂单、货币兑换、玩家转账、贷款付款、股息、税款退款和国债发行；资金托管、实体物品兑换和拍卖成交仍需继续收口到统一跨对象事务协调器。

## 开发与验收规则

- 每个跨系统操作必须有稳定主体 ID、来源或请求 ID、币种、金额、时间和状态。
- 重复调用不得重复扣款、发放、计税、交付或增加负债。
- 持久化顺序必须允许重启后继续完成，或进入明确的退款、损失、违约或坏账状态。
- `/economy-audit` 会报告金融交易日志和每日结算阶段日志中仍未完成的步骤，便于定位重启恢复或人工处理对象。
- `/economy-audit` 还会校验两类结算日志的主体、阶段、状态、金额和时间边界，避免异常日志被当作正常恢复记录。
- `/economy-audit` 还会校验汇兑、玩家转账、贷款发放和贷款还款恢复记录的主体、币种、金额、期限与利息拆分。
- `/economy-audit` 还会校验银行现金存款与债务还款意图的账户、币种、现金前置余额和债务前置余额。
- `/economy-audit` 还会对在线玩家按银行账户重算存款、贷款和逾期敞口，并与持久化风险快照做差异校验。
- `/economy-audit` 还会按总债务与逾期债务重算金融风险占比，发现快照字段之间的派生值不一致。
- `/economy-audit` 还会在银行日结完成后校验损失准备金是否等于逾期银行敞口的 50%目标，并检查未初始化资本账本是否保持空状态。
- `/economy-audit` 还会校验银行流动性快照按天严格递增、提款不超过存款，发现加载旧存档后的历史乱序。
- `/economy-audit` 还会检查拍卖活动记录、历史出价、结算标记和挂单恢复意图，防止已结算拍卖继续占用商品托管。
- `/economy-audit` 还会把拍卖金融阶段日志与结算标记关联，检查无出价退货或有出价交付/收款/税务是否完整。
- `/economy-audit` 还会报告拍卖、商品、证券、供应订单、银行、汇兑和玩家转账等跨对象待处理记录，便于确认恢复任务是否仍有遗留。
- `/economy-audit` 还会检查通用合同的履约数量、完成前提和违约暴露金额，发现跨系统同步后的账本不变量异常。
- `/economy-audit` 还会检查政府财政流水和债券持仓的金额、余额、期限与利率边界。
- `/economy-audit` 还会检查银行风险敞口、金融风险快照和流动性快照的非负性及范围边界。
- `/economy-audit` 还会检查银行资本、累计损益和损失准备金账本是否出现溢出哨兵值或非法准备金。
- `/economy-audit` 还会检查家庭消费记录是否对应真实家庭，且数量、单价和总额一致。
- `/economy-audit` 还会检查住房租约区域是否与家庭当前区域一致。
- `/economy-audit` 还会检查有效雇佣是否对应家庭和企业，并发现同一劳动者的重复有效雇佣。
- `/economy-audit` 还会发现非 ACTIVE 企业残留的有效雇佣。
- `/economy-audit` 还会检查工资账户的结算日、欠薪边界和雇佣来源，发现孤立欠薪债权。
- `/economy-audit` 还会检查供应订单托管是否仍有订单依据，以及终态订单是否残留托管余额。
- `/economy-audit` 还会检查商品与股票挂单的参与者、标的、数量、价格、时间和订单编号，避免无效挂单继续参与撮合。
- `/economy-audit` 还会检查物流在途、已交付和已丢失记录的字段边界及 shipment ID 唯一性，防止同一批货物同时处于多个结算终态。
- `/economy-audit` 还会检查市场离线邮箱中的玩家、币种、余额和物品标识，避免离线结算队列保存非法资产。
- `/economy-audit` 还会核对待恢复的商品/股票成交意图与订单快照，允许合法的完全成交订单消失，但拒绝数量、买卖方或标的不一致的意图。
- 新玩法必须同时提交实现、持久化、测试和对应系统日志；只写界面或只写内存状态不算完成。
- 经济参数应有现实含义和边界说明，但不直接复制现实国家的完整法律制度。
