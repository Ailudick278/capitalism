# 工业气瓶

- ID：`capitalismmod:gas_cylinder`，1×1 占地、2 格高，放置时要求上方空间和底部支撑。
- 外观：16 面圆柱、底圈、分层收肩、瓶颈、黄铜阀体、侧喷嘴、红色圆环手轮和瓶身标签。使用独立生成的 128×128 青蓝烤漆、黄铜、银灰钢材、红色烤漆和深灰底圈贴图，标签为 128×192。保持干净新瓶质感，无污损、划痕或掉漆。
- 瓶身使用按圆周和总高度连续展开的 UV，上下两格接缝对齐。标签标注 COMPRESSED GAS / 15 MPa；此为外观标记，当前无压力数值模拟。
- 原图保存在 `tmp/gas-cylinder/material-originals`，内置图像生成工具的提示词保存在 `tools/gas-cylinder-material-prompts.json`。`tools/preview-gas-cylinder.ps1` 输出材质映射预览，不代表游戏截图。
- 右键上半部阀门区域（上半格相对高度 ≥ 0.65）开关，支持手持物品操作。开关使用服务端方块状态同步，手轮角度及指示色改变。
- 打开后由服务端每 3 tick 发出定向白色云雾粒子，间歇播放轻微放气声；关闭后停止下一次喷气。已排出的粒子自然消散。
- 上下半部联动移除；仅下半部配置掉落，创造模式拆上半部时抑制下半部掉落。禁止活塞推动，不允许水下放置。
- 合成：` C `/`I I`/`III`，C 为铜锭，I 为铁锭；也可在创造物品栏获取。
- 当前为外观交互方块，不消耗气体，不接入容量、充装、管道、伤害或压力模拟。

验证：Java 编译、JAR 打包和模型/方块状态资源检查。尚未进行游戏内验收。需检查四个朝向喷气、开关与重进存档、拆除上下半部及支撑、创造模式无掉落和联机同步。
