# 土地系统开发进度

## 已实现功能

- 支持区块认领、释放、权限、用途、租赁、转让和拍卖。
- 支持租金、押金、欠租、土地税、用途限制和产权历史。
- 租赁结束、押金退还、欠租形成和恢复均使用持久化结算步骤；服务器重启后可继续完成且不会重复入账。
- 土地转让和拍卖退款使用订单/拍卖级到账凭证，在线与离线玩家统一通过邮箱结算。
- 主动释放土地先持久化退款凭证，再删除产权；中断重试不会出现产权已删除但退款丢失或重复退款。
- 土地参考估值现在结合区域人口压力和公共服务质量；人口集中提高需求溢价，服务不足降低溢价，且影响有明确上限。

## 存在的问题

- 地价仍未充分受到交通拥堵、企业选址需求和实际成交深度影响；当前已接入人口与公共服务两个区域变量。
- 租赁续期、违约收回、争议和规划规则仍不完整。
- 土地转让的付款、产权变更、市场流水和卖方到账仍跨越多个账本，尚未由统一事务协调器原子提交。

## 后续方向

1. 建立区域地价和土地用途的供需模型。
2. 接入城市设施、人口迁移和企业选址。
3. 完善租赁合同、押金、违约和争议流程。
4. 将土地交易、拍卖和租赁结算纳入统一金融/合同结算日志。
