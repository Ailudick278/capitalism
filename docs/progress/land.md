# 土地系统开发进度

最后更新：2026-09-06

## 已实现功能

- 以区块为单位支持土地选择、认领、释放、租赁、转让和拍卖。
- 支持土地用途、关联企业、资源数量、估值、所有者、租户、受信任玩家和访客权限。
- 支持租金、保证金、欠租、宽限期、土地税、转让税、土地交易和操作日志。
- 支持土地状态、产权、租约、信托、拍卖和税务数据持久化与网络同步。
- 土地租赁命令已统一通过服务层，租金欠款进入独立债务账本，支持在线补缴和离线邮箱收款。
- 土地拍卖支持托管退款、税款清偿、产权转移、卖方分成和分步骤幂等结算。
- 世界地图已作为土地选区入口，但与土地领域逻辑保持分离。

## 存在的问题

- 所有权、租赁、转让、出售、拍卖、欠税处置之间的状态互斥和流转仍需统一。
- `SavedData` 跨文件结算没有真正的原子事务，极端崩溃时仍有一致性窗口。
- 土地 UI、估值、基础设施、位置和周边市场联动仍较基础。
- 租赁合同的续租、违约、收回和争议处理尚未完整模拟。

## 后续方向

1. 建立完整土地状态机和可追踪的产权历史。
2. 统一报价、合同、付款、税费、过户、失败回滚和审计流程。
3. 完善租赁合同、押金、续租、违约、收回和争议处理。
4. 将土地价值、用途、位置、基础设施和区域市场纳入估值模型。
5. 增加土地与企业、税务、物流和地图覆盖层的事件接口。
