# 银行与货币系统开发进度

## 已实现功能

- 支持多货币、钱包、现金支付、兑换、汇率查询和转账。
- 支持银行账户、存款、定期存款、贷款、利息和交易记录。
- 转账使用持久化请求编号和回执，日结具备重复执行保护。
- 管理员可使用 `/economy-audit` 检查企业账本余额链、家庭现金、工资债务和劳动记录。

## 存在的问题

- 银行资产负债表、准备金和流动性压力测试仍不完整。
- 不同系统之间的跨账本事务仍依赖各领域的阶段标记。
- 审计目前是只读诊断，不能自动恢复中断的跨账本事务。
- 汇率和货币供给尚未受到人口、贸易和政策共同影响。

## 后续方向

1. 建立统一经济事件和结算凭证。
2. 将工资、物流和税务结算扩展为统一的可恢复事务。
3. 完善银行资本、流动性、信用和挤兑模型。
