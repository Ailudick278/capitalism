# 银行与货币系统开发进度

最后更新：2026-09-06

## 已实现功能

- 支持 USD、CNY、EUR、RUB 等货币，并使用最小货币单位精确存储。
- 支持汇率查询、货币兑换、钱包和个人资产管理。
- 支持借记账户、信用账户、活期存款、定期存款、存取款、转账、贷款、还款和利息结算。
- 支持银行卡、账户数据持久化、交易记录和客户端同步。
- 支持信用评估、债务利用率、还款记录、逾期限制以及小数利息余数持久化。
- 现金支付支持纸币/硬币组合、找零和失败回退；转账会校验手续费、扣款额和入账金额溢出。

## 存在的问题

- 汇率与贸易、供需、货币供给和区域经济的联动仍较简单。
- 信用额度、抵押品、担保人、银行流动性、坏账和风险处置尚未形成完整模型。
- 钱包、银行账户、企业金库和跨系统结算仍需要统一资金凭证与审计口径。
- 银行结算虽已具备幂等和补结算能力，但跨账本原子性仍有限。

## 后续方向

1. 建立统一资金转移事务，覆盖扣款、入账、找零、回滚和审计。
2. 完善信用评分、授信、抵押、逾期、坏账和银行准备金规则。
3. 建立银行对账单、手续费、现金库存和流动性管理。
4. 让汇率与贸易、库存、市场区域和经济周期产生可解释的联动。
