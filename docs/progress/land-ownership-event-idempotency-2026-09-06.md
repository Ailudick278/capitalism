# 土地产权历史事件标识（2026-09-06）

## 本阶段实现

- `LandOwnershipSavedData` 为产权事件增加可选 `eventId`，旧存档没有该字段时仍可读取。
- 主动转让和土地拍卖使用各自结算流程的唯一事件号写入产权历史。
- 新事件按事件号幂等；旧调用仍保留原有“所有人 + 原因”兼容去重规则。
- 同一所有人未来再次合法取得同一土地时，不会因为原因相同而丢失新的产权事件。

## 现实逻辑对应

产权登记记录的是每次可识别的取得/变更事件，而不是只记录某个所有人曾经出现过。事件号也便于把产权、市场成交和税务票据关联起来。

## 后续方向

- 将土地交易的事件号继续贯通到税务票据和托管结算状态。
- 增加产权历史的管理员查询与异常登记修复入口。
