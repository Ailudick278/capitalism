# 界面、网络与基础设施开发进度

最后更新：2026-09-06

## 已实现功能

- 使用 NeoForge 菜单、屏幕、按键映射和 payload 实现客户端/服务端交互。
- 已建立银行、税务、土地、市场、供应链、证券、企业和地图等主要界面。
- 已建立操作结果反馈、权限入口、数据同步 payload 和 SavedData 持久化。
- 世界地图已拆分为独立菜单/屏幕，土地界面通过入口调用地图。
- 构建流程支持生成 JAR 后复制到本地 Minecraft 测试实例。
- 已通过构建和单元测试验证核心源码、资源、网络结构和持久化代码。

## 存在的问题

- 当前界面主要用于功能验证，视觉风格、布局和交互一致性仍需重做。
- 网络请求的权限校验、参数校验、错误码、重复请求和事务模板尚未完全统一。
- 大量数据同步仍有全量传输场景，客户端缓存、版本号和增量同步需要加强。
- 中文路径下的 Gradle 测试可能触发 JDK/Gradle worker 类路径兼容问题。

## 后续方向

1. 抽象统一的操作结果、错误码、权限校验和服务端事务模板。
2. 完善增量同步、批量同步、版本号和客户端缓存失效策略。
3. 重做主要界面，并保持领域服务和网络协议稳定。
4. 建立跨系统调试日志、数据迁移、存档兼容和自动化验证流程。
