# 政府与宏观政策系统开发进度

最后更新：2026-09-07

## 已实现功能

- 政府储备、每日福利、财政支出和税收收入持久化，支出不能超过财政余额。
- `/government` 命令支持福利、财政存入、政策利率、通胀目标和公开市场政策等基础操作。
- 福利按模拟日和家庭 ID 幂等发放，家庭现金增加后会进入下一轮消费和市场需求。
- 已缴税款按每笔支付即时进入政府储备，支持部分缴款，并保存原币金额和换算金额。
- 政府税收收入会与具体税款支付和税单逐笔关联，经济审计会核对主体、税种、币种、金额和汇率结果。
- 政府支出会依据稳定来源 ID 汇总为社会保障、公共服务、公共建设、货币政策和金融稳定等类别，`/government info` 可查看当日分类支出。
- 住房、学校和诊所按日产生维护支出；财政不足时设施折旧，公共服务评分随之下降。
- 失业救济基于家庭就业记录、失业持续时间和福利水平，并受家庭资格、财政余额和幂等凭证约束。
- 政策利率会传导到银行存款、贷款年利率和企业授信；债券发行与回购也使用政策利率和财政余额约束。
- 银行流动性、货币供给、CPI 通胀、金融风险和公开市场操作均纳入每日结算与持久化快照。

## 存在的问题

- 财政收入与支出已经集中记录，但预算仍主要是单一财政池，尚未按地区、部门和税种编制预算。
- 福利资格已有失业和就业持续时间条件，但尚未区分失业保险缴费、最低生活保障和多层次社会保障。
- 政策利率、CPI 和货币供给已经形成基础传导，但利率对投资、生产和就业的滞后反应仍较简化。
- 公开市场操作目前主要回购国债，尚未形成完整的央行资产负债表和银行间市场。

## 后续方向

1. 建立按税种、地区和部门划分的财政预算，并与设施供给和公共服务质量联动。
2. 增加失业保险缴费、最低生活保障和自动稳定器资格规则。
3. 将公开市场操作扩展为央行资产负债表、银行间融资和市场报价机制。
4. 继续细化财政乘数、利率滞后、通胀预期和货币供给传导，并用固定种子压力测试验证资金守恒。
