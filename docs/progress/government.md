# 政府与宏观政策系统开发进度

最后更新：2026-09-06

## 已实现功能

- 政府储备、每日低福利家庭补助和支出流水持久化。
- `/government policy benefit <dailyMinor>` 设置每日补助，`/government treasury deposit <amountMinor>` 注入储备，`/government info` 查看状态。
- 补助按模拟日和家庭 ID 幂等发放，家庭现金增加后会进入下一轮消费和市场需求。
- 政府支出不能超过储备，支出流水记录支付后余额，避免凭空创造货币。

## 存在的问题

- 储备目前由管理员注入，尚未自动接入税收、国债和公共服务预算。
- 补助对象暂以低福利作为失业/困难代理，尚未独立记录失业持续时间和资格审核。
- 尚未实现利率、货币供给、通胀目标和逆周期税率等完整宏观政策工具。

## 当前阶段补充

- 已缴清税单会自动进入政府储备；非默认货币税款按当前汇率折算为默认货币。
- 税款现在按每笔成功缴款即时归集，部分缴款也会进入政府储备，不必等到账单完全结清。
- 税收以支付流水 ID 做幂等键，并持久化税种、原币种、原金额和折算金额，避免事件重放造成重复收入。
- `/government info` 现在同时显示转移支付流水数和税收收入流水数。
- 住房、学校和诊所现在每天产生维护支出；财政无法覆盖时，每类设施每天折旧一个单位，公共服务评分会随之下降。
- 公共设施维护使用独立的“日期—区域—设施”幂等键，重启或补结算不会重复扣款。
- 失业救济资格现在基于家庭持久化的就业记录：累计就业至少 7 天、连续失业至少 3 天且福利低于 70 时才可领取，最长领取 90 天。
- 单个家庭的每日救济不超过其基本生活需求的 60%，避免政策参数失控造成过度转移。
- 新增持久化政策利率（基点）；`/government policy rate <basisPoints>` 会同步影响存款和贷款年利率，范围为 -100% 到 +200%。
- 银行每日结算读取政策利率后再计算复利，利率变化会传导到居民储蓄收益和借款利息。

## 后续方向

1. 将税收收入扩展为按缴款流水即时归集，并建立按税种、地区的公共支出预算。
2. 增加失业保险、最低生活保障和自动稳定器资格规则。
3. 将政策利率进一步接入企业贷款、债券定价和投资决策，建立金融风险传导。
