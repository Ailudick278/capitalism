# 政府与宏观政策系统开发进度

最后更新：2026-09-07

## 已实现功能

- 政府储备、每日低福利家庭补助和支出流水持久化。
- `/government policy benefit <dailyMinor>` 设置每日补助，`/government treasury deposit <amountMinor>` 注入储备，`/government info` 查看状态。
- 补助按模拟日和家庭 ID 幂等发放，家庭现金增加后会进入下一轮消费和市场需求。
- 政府支出不能超过储备，支出流水记录支付后余额，避免凭空创造货币。
- 政府补助采用可恢复结算凭证：先记录政府支出，再将款项写入家庭；服务器在两步之间重启时，下一次日结会依据凭证补发，不会重复扣款或漏记财政支出。
- 已缴清税单会自动进入政府储备；非默认货币税款按当前汇率折算为默认货币。
- 税款现在按每笔成功缴款即时归集，部分缴款也会进入政府储备，不必等到账单完全结清。
- 税收以支付流水 ID 做幂等键，并持久化税种、原币种、原金额和折算金额，避免事件重放造成重复收入。
- `/government info` 现在同时显示转移支付流水数和税收收入流水数。
- 住房、学校和诊所现在每天产生维护支出；财政无法覆盖时，每类设施每天折旧一个单位，公共服务评分会随之下降。
- 公共设施维护使用独立的“日期—区域—设施”幂等键，重启或补结算不会重复扣款。
- 失业救济资格现在基于家庭持久化的就业记录：累计就业至少 7 天、连续失业至少 3 天且福利低于 70 时才可领取，最长领取 90 天。
- 单个家庭的每日救济不超过其基本生活需求的 60%，避免政策参数失控造成过度转移。
- 新增持久化政策利率（基点）；`/government policy rate <basisPoints>` 会同步影响存款和贷款年利率，范围为 -100% 到 +200%。
- 银行每日结算读取政策利率后再计算复利，利率变化会传导到居民储蓄收益和借款利息。
- 企业贷款承做也使用政策调整后的实际年利率，并以该实际利率参与债务覆盖率审核和后续逾期计息。
- 政府债券购买资金现在进入财政储备，债券新发行票息也随政策利率调整；购买失败时会退回资金，不会留下无资金支撑的持仓。
- 企业贷款超过配置宽限期仍未偿还时会自动进入清算状态，停止新经营活动并通知业主；最终资产变现和优先清偿仍走既有清算流程，保留可审计的人工确认步骤。
- 每个模拟日持久化金融风险快照，统一统计企业贷款、同行贷款和政府债券负债，以及逾期敞口、逾期贷款数和逾期占比；`/economystats` 可查看最近快照。
- 风险快照进一步纳入在线玩家银行信用债务，并按银行账户逾期状态计入逾期敞口，使银行流动性、个人信用和系统性危机使用同一风险口径。
- 风险快照现在会反向约束企业授信：逾期占比按比例压缩债务上限，达到 60% 时冻结新增企业贷款；风险回落后自动解除，`/economystats` 同时显示授信系数。
- 金融危机状态按逾期占比 60% 触发、40% 恢复，采用滞回阈值避免在临界值反复切换；状态和起始日持久化，并在 `/economystats` 显示。
- 政府债券到期或提前兑付会从财政储备扣款，储备不足时暂缓兑付而不凭空创造货币。
- 当逾期债务占比超过 20% 时，新发政府债券会加入流动性风险溢价，最高额外增加 5 个百分点；这会把危机期间的融资成本和未来偿付压力反馈到风险快照。
- 银行现在每日持久化在线账户的存款与信贷敞口；系统性危机期间，提款总额限制为观测存款的 10%，正常时期不限制提款，避免银行挤兑被简单模拟成无限流动性。
- 公共住房租金按家庭和模拟日幂等归集，已缴租金进入政府财政收入，并与住房租约欠租记录分离保存。
- 系统性危机期间，银行新增个人信用贷款还受到 80% 贷款/存款比上限约束；危机解除后恢复正常授信规则。
- 每日根据食品、能源和生活用品市场价持久化固定消费篮子 CPI；`/economystats` 显示指数和日变化，基期为 10000。
- 可选自动通胀规则以 CPI 目标为锚，每个模拟日最多调整政策利率 25 个基点，默认关闭，避免覆盖管理员手动利率。

## 存在的问题

- 财政收入和支出已接入税收、国债及公共设施维护，但预算仍是单一财政池，尚未按地区和部门编制预算；公共设施维护已使用日级支出收据，重复结算不会误触发设施折旧。
- 补助资格已使用失业和就业持续时间，仍未区分家庭成员、失业保险缴费和多层次社会保障。
- 政策利率已实现传导，CPI 目标和可选自动调息已实现；货币供给与公开市场操作仍未实现。

## 后续方向

1. 建立按税种、地区和部门划分的财政预算，并与设施供给和服务质量联动。
2. 增加失业保险缴费记录、最低生活保障和自动稳定器资格规则。
3. 将政策利率扩展到货币供给、通胀目标、投资决策和公开市场操作。
