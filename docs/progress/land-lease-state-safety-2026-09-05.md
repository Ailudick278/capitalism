# 土地租约状态安全 - 2026-09-05

## 已实现

- `LandHelper.lease` 拒绝覆盖已有有效租约。
- 有未结清租金债务时不能创建新租约。
- `LandHelper.release` 拒绝在租约有效或租金欠款未结清时释放土地。
- 约束放在领域服务层，而不是只放在命令层，因此地图界面和网络请求也受到同样保护。

## 现实逻辑

土地所有权与租赁权是不同的权利状态。出租人不能通过重新出租或直接删除土地记录来绕过既有租约；租约终止时，未付租金仍应作为可追收债务保留。

## 后续方向

- 增加双方提前终止租约的协议流程和违约补偿规则。
- 继续统一土地转让、出售和拍卖对租约状态的校验。
