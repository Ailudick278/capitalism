# 时间与日历系统开发进度

## 已实现功能

- 使用统一的游戏 tick 与经济日作为跨系统时间基础，固定映射到公历日期。
- 支持日期、星期、时间段和经济周期换算，税务、合同、贷款、利息和事件系统可共享同一时间层。
- 日结阶段使用持久化阶段日志和完成标记，支持服务器重启后继续结算。

## 存在的问题

- 游戏内视觉时间与经济时间仍是两个概念，界面需要更清楚地标注经济日。
- 节假日、季节和地区时区尚未影响劳动、消费和生产行为。

## 后续方向

1. 增加节假日、季节和可配置经济日历事件。
2. 将公共假期、发薪日、税务期限和市场到期日统一接入事件调度器。
3. 为长时间离线结算增加分段进度和更细的恢复审计。
