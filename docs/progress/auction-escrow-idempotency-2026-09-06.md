# 拍卖托管结算幂等性（2026-09-06）

## 本次完成

- 新增拍卖结算账本，按拍卖单号记录已完成的托管释放或成交结算。
- 流拍时返还卖家物品后记录结算，再删除拍卖单。
- 成交时向赢家交付物品、向卖家付款并完成税务登记后记录结算，再删除拍卖单。
- 无出价撤单也使用同一账本，避免托管物品因异常中断丢失或重复返还。
- 新增竞价操作账本；竞买人付款和前一最高价退款完成后，即使最高价写回被中断，也不会重复扣款或重复退款。

## 现实逻辑对应

拍卖中的商品和竞价款在成交或撤单前属于托管资产；拍卖结束后应完成一次结算并关闭订单。本次增加了结算凭证，使拍卖记录与托管资产释放保持一致。
