# 动态经济事件系统开发进度

## 已实现功能

- 使用统一事件对象记录事件 ID、系统、类型、起止时间、目标主体、幅度和状态。
- 商品价格冲击支持正向和负向基点幅度，按持续时间传导到商品价格更新。
- 事件到期后自动标记为 `resolved`，重复创建同一事件 ID 不会重复生效。
- 商品价格更新和每日结算都会检查到期事件，因此市场暂停时事件状态仍会随模拟时间恢复。
- `/economicevent priceShock <eventId> <itemId> <shockBps> <days>` 可由管理员创建可复现的市场冲击。
- `shockBps` 为基点：正值表示供给收缩/价格上行，负值表示需求收缩/价格下行；例如 `2500` 代表约 25%。

## 存在的问题

- 当前冲击需要管理员触发，尚未根据灾害、贸易中断、失业或环境状态自动生成。
- 事件主要影响商品价格，尚未统一影响就业、迁移、财政支出、物流能力和金融风险。
- 多个同时发生的事件目前按基点简单相加，尚未实现传播网络和事件优先级。

## 后续方向

1. 增加固定种子和事件模板，让供给中断、需求骤降、自然灾害和金融危机可重复模拟。
2. 建立区域传播、持续期和恢复任务，使事件影响物流、就业、价格和迁移。
3. 将事件与保险、政府救济、企业现金流和金融风险状态机统一连接。
