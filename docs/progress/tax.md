# 税务系统开发进度

最后更新：2026-09-06

## 已实现功能

- 建立独立税务系统，支持土地持有税、企业所得税、个人经营所得税、增值税、转让税、印花税和资本利得税等税种框架。
- 支持税率规则、税期、税单、税务总账、税款支付、交易记录、欠税和税期锁定。
- 支持企业/个人收入凭证、采购成本凭证、费用凭证、进项税额、抵扣和周期汇总。
- 支持申报、缴税、补税、税务执法、滞纳金、退税申请、规则审核、管理员审批和通知。
- 支持税务更正申请、审核日志、审计记录、网络同步和持久化恢复。
- 企业所得税支持亏损结转；证券印花税、土地拍卖税款和供应订单抵扣已接入统一结算路径。
- 税务总账、凭证、退税和抵扣流程已加入多项幂等与存档校验。

## 存在的问题

- 税率、免征额、扣除项、资格条件和申报周期仍主要是游戏规则，配置化程度不足。
- 现实税制中的主体认定、发票链、跨地区征税、税收协定和争议处理尚未完整模拟。
- 预缴、抵扣结转、免税减免、资本利得、继承赠与和多主体关联交易仍需深化。
- 自动审核、管理员审核和税务执法之间的责任边界需要进一步明确。

## 后续方向

1. 将税率、税期、免税、抵扣、滞纳金和资格条件统一配置化。
2. 建立计税、申报、审核、缴纳、补税、退税和更正状态机。
3. 完善发票链、预缴、抵扣结转、跨地区税务和税务争议。
4. 将企业、土地、市场、证券、物流和继承事件统一接入应税事件接口。
5. 增加税务报表、审计视图和每笔税款来源追踪。
