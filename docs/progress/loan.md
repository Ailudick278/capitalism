# 贷款系统开发进度

## 已实现功能

- 支持玩家间贷款、银行贷款和企业贷款的基础流程。
- 支持利息、还款计划、逾期、通知、抵押物和企业停业约束。
- 个人贷款还款凭证按稳定的贷款、时间、金额和剩余本金键去重，重复恢复不会产生相同的还款记录。
- 个人贷款扣款现在写入稳定支付引用；重试时若扣款日志已经落账，会跳过第二次扣款并继续完成贷款状态、还款凭证和出借人到账。
- 命令层已移除重复的旧版还款实现，所有 `/repay` 调用统一经过共享还款服务，避免未来入口分叉出不同的账本规则。
- 带稳定引用的支付日志自身也按引用去重，避免重复恢复污染支付审计；无引用的历史支付日志保持兼容。

## 存在的问题

- 各类贷款合同、费用、信用评分和风险分类尚未完全统一。
- 违约后的催收、清算、重组和破产流程仍较简单。
- 借款人扣款、贷款状态变更和还款凭证写入仍跨越多个持久化边界，完整扣款确认状态机仍在完善。

## 后续方向

1. 统一贷款合同、账本、还款和违约状态。
2. 建立基于现金流、抵押物和历史履约的信用模型。
3. 接入银行资本充足率和系统性金融风险。
