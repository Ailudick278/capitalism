# 贷款系统开发进度

最后更新：2026-09-06

## 已实现功能

- 支持点对点贷款和企业贷款的申请、放款、还款、到期、逾期与持久化。
- 支持本金、利息、期限、分段计息、逾期利息、部分还款和利息优先分配。
- 企业贷款接入企业金库、企业账本、现金流评估、偿债覆盖率和信用报告。
- 支持企业债务倍数、现金流倍数、最长期限和最低覆盖率配置。
- 支持抵押品估值报告，并排除质检冻结、拒收和受限库存。
- 支持贷款还款台账、历史查询、离线通知和日结幂等处理。

## 存在的问题

- 点对点贷款、银行贷款和企业贷款的合同、费用、还款计划规则尚未完全统一。
- 抵押登记、担保人、优先受偿、违约处置、催收和债务重组尚未完整实现。
- 部分还款仍有不直接冲减本金的边界，贷款现金流与企业、土地、税务联动仍需加强。
- 贷款结算跨多个持久化账本，极端崩溃时仍需更强的事务协调。

## 后续方向

1. 统一贷款合同、还款计划、费用、状态和结算凭证。
2. 完善抵押物、担保人、信用等级、违约、催收和清算。
3. 支持分期、提前还款、展期、罚息和债务重组。
4. 将贷款风险纳入个人、企业和银行的综合财务状态。
