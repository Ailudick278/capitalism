# 世界地图系统开发进度

最后更新：2026-09-05

## 已实现功能

- 世界地图作为独立的可视化子系统存在，与土地领域逻辑解耦。
- 支持单独入口打开世界地图，也支持从土地界面进入地图进行区块选择。
- 按维度保存已探索区块的地图色块数据。
- 地图数据使用服务端 SavedData 持久化，重新进入世界后可恢复。
- 支持地图拖拽、缩放、玩家位置标记和已探索区块的选择反馈。
- 支持地形颜色、明暗/高度表现和方块变化后的地图缓存刷新。
- 支持世界地图缩放范围和区块加载半径配置；当前加载半径上限为 24，默认值为 8。
- 支持地图瓦片同步和土地覆盖层同步。

## 当前边界与待处理问题

- 地图是土地系统的可视化工具，不负责所有权、税务或交易规则。
- 地形渲染仍需要持续平衡表现质量、更新及时性和客户端性能。
- 后续 UI 重做时应保持 WorldMapMenu/WorldMapScreen 的独立入口和调试能力。

## 后续开发方向

1. 继续优化瓦片缓存、增量刷新和批量同步，减少缩放、拖拽和探索时的性能开销。
2. 明确不同维度的地图缓存生命周期、颜色规则和维度切换体验。
3. 为地图覆盖层建立统一接口，供土地、物流、企业和其他模块按需接入。
4. 增加图例、过滤器和选区预览，但不把业务规则写入地图渲染层。
5. 后续使用 LDLib2 重做 UI 时，优先替换表现层，不改变地图数据模型。
