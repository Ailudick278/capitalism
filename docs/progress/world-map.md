# 世界地图系统开发进度

最后更新：2026-09-06

## 已实现功能

- 世界地图作为独立可视化子系统，与土地、物流和企业领域逻辑解耦。
- 支持独立打开地图，也支持从土地界面进入地图选择区块。
- 按维度保存已探索区块的地图瓦片，并使用服务端 `SavedData` 持久化。
- 支持拖拽、缩放、玩家位置、已探索区块、地形颜色、明暗/高度表现和缓存刷新。
- 支持土地所有权、油田资源、企业经营地点和物流节点四类覆盖层。
- 区块详情可显示土地状态、油田储量、企业地点名称和物流设施类型。
- 支持地图瓦片、土地覆盖层和物流节点覆盖层同步；加载半径默认 8、上限 24。

## 存在的问题

- 地图只负责展示，不负责所有权、税务、交易、运输时效或容量规则。
- 大范围探索、缩放、拖拽和瓦片同步仍需继续优化客户端性能。
- 不同维度的缓存生命周期、颜色规则和切换体验尚未完全统一。
- 历史存档中可能存在已放置但未登记到新节点数据中的物流设施。

## 后续方向

1. 优化瓦片缓存、增量刷新、批量同步和维度切换。
2. 为覆盖层建立统一接口、图例、过滤器和选区预览。
3. 增加物流运力、风险、区域和企业经营状态摘要。
4. 为旧存档提供安全的物流节点修复/重建入口。
5. 重做 UI 时只替换表现层，不改变地图数据模型和独立入口。
