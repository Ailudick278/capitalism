# 金融风险与信用

## 已实现功能

- 每个模拟日会汇总企业贷款、玩家同业贷款、银行贷款和债券负债，并统一换算为默认货币。
- 持久化金融风险快照记录总负债、逾期负债、逾期笔数和逾期占比，供命令与其他系统读取。
- 企业贷款使用现金流、债务覆盖率、资本倍数和全系统逾期率进行授信；严重逾期或系统性流动性危机时会停止新增企业贷款。
- 企业贷款现在还会根据已发生的还款行为调整债务上限；新企业不因缺少历史被惩罚，已有记录的企业按行为评分获得 50%–100% 的额度系数。
- 企业贷款利率现在包含基于还款评分的可解释信用利差；有历史企业最高增加 5 个百分点，无历史企业不加价。
- 企业贷款期限现在也按还款评分调整；信用记录较弱的企业获得更短的实际期限，从而更早暴露现金流压力，信用良好或无历史企业不被额外缩短。
- 企业还款评分现在按按时与逾期还款的实际金额加权，避免多笔小额按时还款掩盖一笔大额逾期。
- 已有还款历史的企业贷款会按信用评分检查库存和设备的折价后抵押覆盖；信用越弱，新增贷款需要的可用抵押越高，且已有债务会先占用抵押头寸。
- 银行流动性每日核算存款、贷款、提款和资本缓冲；逾期率达到 20% 后压缩授信，达到 60% 后冻结新增银行和企业信用。
- 银行新增个人贷款在正常时期也受资本充足率上限约束，危机或高逾期时再叠加存贷比与风险折扣。
- NPC 家庭存款与信贷已同时进入银行流动性和货币供给统计，避免居民金融活动只影响单一报表。
- 银行危机支持进入与恢复滞后：风险回落到 40% 以下且没有流动性压力，连续 3 个模拟日后才解除危机。
- 风险、流动性、资本和危机状态都保存在世界数据中，重复日结不会重复记录。
- 经济审计会校验银行暴露、金融风险快照和流动性快照的非负性及范围边界。
- 在线银行账户审计会校验余额、债务和交易历史的币种、类型、金额方向、时间及稳定引用，并与风险敞口快照联动检查。
- 账户级敞口摘要与玩家级聚合必须来自同一同步时间，审计会拒绝跨结算日拼接的风险数据。
- 离线账户索引同时保存交易条数和最后交易时间；玩家上线后会与账户历史核对，发现余额摘要和流水摘要不同步时报告异常。
- 风险索引超过 7 个模拟日未同步时会被经济审计标记为过期；过期数据保留用于风险参考，不会被误当成“没有负债”。
- `/economystats` 会显示过期银行敞口数量；个人新增贷款在敞口过期时暂按正常授信额度的 50% 评估，重新同步后恢复。
- 银行还款会把稳定还款引用写入账户交易历史；审计可将债务减少与同一引用的钱包扣款逐笔核对，崩溃恢复也沿用该引用。
- 企业年度税务收入与费用累计使用持久化来源事件键，结算重试不会重复扩大年度应税基数。
- 公司收入入口同步写入幂等税务收入凭证，收入来源可与企业季度/年度税基逐笔追溯。
- 经济审计会将公司收入凭证与公司账本的同金额、同币种正向入账逐笔核对，并检查凭证来源唯一性与所有者。
- 经济审计会校验 VAT 发票的来源唯一性、方向、税额/抵扣边界、币种和时间字段。
- VAT 发票会与同来源税务账单逐笔关联；输出税账单需匹配纳税主体、币种、税基和未抵扣税额，完全抵扣的发票允许无账单。
- 输入抵扣审计会校验抵扣批次、聚合余额和来源应用标记；已被输出税消耗的历史批次允许清零，但不能出现聚合余额小于可见批次的情况。
- 税款支付会按账单核对支付记录：支付 ID、纳税主体、币种和金额必须有效，支付合计不得超过含滞纳金应付额，并且必须与账单已付金额完全一致。
- 新产生的个人税款支付会保存稳定的钱包扣款引用，经济审计可进一步核对纳税人、币种和金额是否存在真实钱包流水；公司金库和外部收入结算也保存各自的结算引用。
- 政府税收收入会反向关联具体税款支付和税单，审计会核对纳税主体、税种、原币金额及汇率换算后的财政入账金额。
- 每次系统性危机进入和恢复都会写入统一经济事件账本，便于 `/economicevent` 查询当前危机阶段。

## 存在的问题

- 风险目前主要按全系统逾期占比收紧，尚未按借款人行业、抵押品质量和期限结构进行充分差异化定价。
- 企业还款行为已影响额度、利差、期限和新增贷款抵押覆盖要求；抵押品仍是授信快照约束，尚未形成独立质押、处置和优先清偿流程。
- 银行暴露数据主要覆盖已登记的玩家账户；NPC 存贷款已纳入流动性汇总，但离线玩家与 NPC 仍需要统一账户索引。
- 危机处置以数量限制为主，尚未形成存款保险、资产出售、央行最后贷款人和优先清偿等完整处置链。
- 历史存档中的旧税款支付可能没有结算引用，只能继续依赖账单金额对账；新记录已经具备长期稳定的逐笔外键。
- 审计目前是只读诊断，不能自动恢复中断的跨账本事务。

## 后续方向

- 把银行存款、还款和风险处置记录关联到具体金融主体，并为个人钱包支付补充稳定的支付引用。
- 为离线账户建立可查询的持久化账户索引，使账户交易审计和风险敞口校验不再只覆盖在线玩家。
- 为离线账户索引增加交易明细摘要和过期标记，区分“没有负债”和“长期未同步”的账户状态。
- 将过期状态接入风险面板和授信决策，长期未同步账户在重新同步前使用更保守的风险权重。
- 将风险快照扩展为行业、地区和主体级别，引入现金流波动、失业率、房租压力和抵押品折价。
- 为贷款生成可解释的利率、期限和抵押品要求，建立正常、警戒、危机、恢复四档授信产品。
- 增加银行间融资、坏账核销、资产出售和资本补充的可重试结算事务。
- 增加压力测试与历史回放，用固定种子验证挤兑、违约、限贷和恢复不会凭空创造或销毁资金。
