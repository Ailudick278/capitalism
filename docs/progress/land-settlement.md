# 土地租赁结算事务

## 已实现功能

- 租约终止会先建立持久化结算记录，再处理押金扣抵、房东收款、租户退款和欠租转债。
- 房东与租户的押金结算通过市场邮箱凭证到账，在线玩家会立即兑换，离线玩家登录后领取。
- 欠租凭证使用结算 ID，重复恢复不会再次生成同一笔债务。
- 定期租金按“土地 ID—租约到期时间—应付时点”生成稳定账单，保存待处理、已结算和违约状态。
- 租户补缴已结束租约的欠租时，房东到账使用欠租 ID 凭证，追缴重试不会重复支付。
- 服务器每个 tick 检查未完成结算，能够恢复中断的多步流程。

## 当前问题

- 租金定期扣款仍是钱包扣款与租约状态更新的多步操作，尚未具备完整的扣款凭证。
- 租赁争议、提前解约赔偿和租约续期仍未建模。

## 后续方向

1. 为定期租金扣款增加租期账单和可重试扣款凭证。
2. 增加提前解约、维修责任、押金争议和仲裁流程。
3. 将区域租金与人口密度、交通可达性、公共设施和企业需求联动。
