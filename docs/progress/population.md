# 人口与家庭系统开发进度

最后更新：2026-09-07

## 已实现功能

- 家庭以稳定 ID 持久化，记录区域、人口规模、劳动年龄人口、现金、基本生活需求和福利状态。
- 管理员可以按区域生成受控规模的虚拟 NPC 家庭；玩家登录后可登记为家庭主体。
- NPC 可以读取劳动市场岗位、自动匹配并形成雇佣关系；工资日结会进入家庭预算。
- 家庭预算会按规模、福利和商品价格计算食品、能源与生活用品需求，并参与市场需求更新。
- 岗位包含区域标识；低福利家庭在工资不足以覆盖基本需求时，会考虑迁移到外地岗位。
- 迁移会计算目的地租金、通勤代理成本和基础设施摩擦，并在成功时同步住房区域与租约。
- 家庭持久化健康、教育、平均年龄、儿童、劳动年龄和老年人口队列；日结会推进年龄、出生和死亡。
- 健康影响劳动参与率，教育逐步提高基础技能上限，公共服务覆盖会反馈到家庭满意度。
- 家庭消费使用仓储扣货、支付和消费记录的幂等凭证，避免重启造成重复扣货或重复需求。
- 工资、消费、住房和迁移数据纳入经济审计，检查主体、数量、金额和区域关系。
- 住房日结会持久化租金支付凭证；政府、企业房东和私人房东分别必须存在对应收款记录，企业房东收入按主货币单位入账，避免把家庭最小货币单位直接写入企业账本。
- 跨区域就业迁移会持久化迁移事件、来源地区、目的地区、成本和迁移后现金；招聘失败时会撤销迁移事件并恢复迁移成本，经济审计会检查事件身份和家庭归属。
- 家庭每日结算会保存日初现金、工资与福利收入、商品消费、租金和日末现金快照；审计按现金恒等式及消费、租金明细重新核对，避免只看余额而遗漏现金流断点。
- 家庭金融风险会按日持久化，依据现金短缺、租金欠款、工资欠款和失业天数计算 0—100 分；该指标供后续信贷、迁移和福利政策使用，不直接改变家庭余额。
- 金融风险已接入行为层：高风险家庭在收入条件满足时更愿意接受跨区就业，同时可进入福利优先资格；迁移现金门槛仍然有效，风险不会凭空创造资金。
- 家庭消费审计现在要求存在同一消费 ID 的仓储扣货证据，并核对商品与数量，避免只有账面消费记录而没有实际供给。
- 家庭消费还必须在企业分类账中找到同源收入，按默认货币到 USD 的换算结果核对金额，形成“家庭支出—货物扣除—企业收入”闭环。

## 存在的问题

- 居民目前是经济模拟记录，不是 Minecraft 世界中的实体 NPC。
- 消费是虚拟消费者订单，暂不向 NPC 实体发放物品；真实商店库存与消费仍需进一步合并。
- 岗位区域已实现，但坐标级通勤路线和真实交通时间尚未实现，当前使用贸易区域距离代理。
- 迁移已计入住房、通勤和基础设施成本，但搬迁服务商、真实路线和家庭成员逐人迁移尚未实现。
- 家庭仍缺少逐名成员的精确年龄、婚姻关系、亲属图谱、疾病和就学阶段。

## 后续方向

1. 增加坐标级通勤时间、住房租约、押金和搬迁服务市场。
2. 将虚拟消费订单与真实卖方库存、资金托管和交付进一步合并。
3. 增加失业持续时间、培训、成员年龄、婚姻关系和跨代人口流动。
4. 在经济数据稳定后，将部分居民逐步可视化为世界实体，并保持模拟账本为权威数据源。
