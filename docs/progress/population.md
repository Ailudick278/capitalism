# 人口与家庭系统开发进度

最后更新：2026-09-06

## 已实现功能

- 家庭以稳定 ID 持久化，记录区域、人口规模、劳动年龄人口、现金、基本生活需求和福利。
- 玩家登录后自动登记为家庭主体。
- 管理员可以按区域生成受控规模的虚拟 NPC 家庭。
- NPC 可以读取劳动市场岗位、自动匹配并形成雇佣关系。
- 工资日结进入 NPC 家庭预算，基本需求消耗预算，资金不足降低福利。
- 食品、能源和生活用品需求会按家庭规模、福利和商品价格折算，并参与现货市场价格更新。

## 存在的问题

- 当前居民是经济模拟记录，不是 Minecraft 世界中的实体 NPC。
- 基本消费目前通过需求压力影响价格，尚未替家庭实际下单、扣款和领取商品。
- 岗位尚未携带区域位置，迁移和通勤成本还未实现。
- 家庭出生、死亡、年龄结构、教育和家庭合并尚未实现。

## 后续方向

1. 为岗位和家庭增加区域坐标、通勤成本和迁移目标。
2. 将家庭需求升级为食品、住房、能源和服务的实际订单，并接入商品市场。
3. 增加失业持续时间、培训、年龄变化、出生和死亡。
4. 在经济数据稳定后，再把部分居民可视化为世界实体。
