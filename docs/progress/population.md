# 人口与家庭系统开发进度

最后更新：2026-09-06

## 已实现功能

- 家庭以稳定 ID 持久化，记录区域、人口规模、劳动年龄人口、现金、基本生活需求和福利。
- 玩家登录后自动登记为家庭主体。
- 管理员可以按区域生成受控规模的虚拟 NPC 家庭。
- NPC 可以读取劳动市场岗位、自动匹配并形成雇佣关系。
- 工资日结进入 NPC 家庭预算，基本需求消耗预算，资金不足降低福利。
- 食品、能源和生活用品需求会按家庭规模、福利和商品价格折算，并参与现货市场价格更新。
- 岗位支持区域标识；低福利居民会在工资足以覆盖家庭基本需求时迁移到外地岗位。
- 家庭持久化健康和教育水平；每日结算会根据诊所、学校覆盖率更新两项指标，并同步劳动档案。
- 健康水平决定劳动参与率，教育水平逐步提高基础技能上限，形成公共服务到就业能力的反馈。
- 迁移判断会参考目的地物流基础设施的连通性；设施越少，迁移摩擦成本越高，避免仅凭名义工资产生不现实的跨区迁移。

## 存在的问题

- 当前居民是经济模拟记录，不是 Minecraft 世界中的实体 NPC。
- 当前消费是虚拟消费者订单：会持久化商品、数量、单价和支出，并进入市场需求量；暂不向 NPC 实体发放物品。
- 岗位已有区域标识；坐标级通勤路线尚未实现，目前使用贸易区域距离代理。
- 当前迁移已计算目的地租金、通勤代理和基础设施摩擦，但尚未扣除一次性搬迁支出。
- 当前迁移摩擦以区域基础设施代理，尚未接入真实住房、通勤路线和一次性搬迁支出。
- 家庭出生、死亡、年龄结构和家庭合并尚未实现。
- 当前教育和健康是家庭平均指标，尚未拆分到家庭成员年龄、疾病和就学阶段。

## 当前阶段补充

- NPC 家庭现在按健康、福利和家庭规模进行确定性出生/死亡抽样；日种子由家庭 ID 和模拟日构成，重启不会改变结果。
- 当前模型仍不拆分家庭成员年龄结构、婚姻/家庭合并和跨代教育路径；这些属于下一层人口细化。

## 后续方向

1. 为岗位和家庭增加坐标、通勤成本、住房和迁移费用。
2. 将虚拟消费者订单与真实卖方库存、资金托管和交付进一步合并。
3. 增加失业持续时间、培训、成员年龄变化、家庭合并和跨代人口流动。
4. 在经济数据稳定后，再把部分居民可视化为世界实体。
