# 银行界面

## 已实现功能

- 银行 Screen 使用单一 LDLib2 UI 树管理导航、账户摘要、表单和确认页。
- 提供账户总览、现金存取、转账、贷款/还款、定期、兑换、流水及开户补卡入口。
- 按账户 ID 保持选择，接收新账户快照后刷新界面；输入金额及收款人保存在 Screen 状态中。
- 确认操作使用界面内确认页，提交固定的 payload；返回修改不关闭服务端容器。
- 转账校验 19 位收款卡号、禁止转给当前账户；金额校验正整数及最小货币单位转换溢出。
- 购汇输入含义与现有服务端一致：原币种为配置的基准货币时输入到账外币金额，否则输入支出金额。
- 流水按最新优先分页，业务类型/日期与金额分栏显示；常用交易类型使用中文名称。
- 侧栏按业务分组，现金存取、贷款还款、定期储蓄使用页内标签；当前导航采用强调色，次要入口降低视觉权重。
- 账户选择使用显式列表，币种在总览中直接选择；余额、贷款与定期分开展示。
- 定期支取使用独立分页，小窗口也可访问；较小窗口把存款期限压缩为选择按钮。
- 内容卡片、按钮采用细微圆角；确认页突出核对步骤，提交提示使用中性/成功色。

### 设计参考

- [Mercury Personal](https://mercury.com/personal-banking)：账户总览、资金信息与业务入口的层级。
- [Mercury balances](https://support.mercury.com/hc/en-us/articles/28767842120852-Understanding-your-Mercury-balances)：分清可用余额与其他资金概念，不把不同币种直接相加。
- [Wise Design](https://wise.design/design-at-wise/get-started)：统一基础样式和可复用组件的设计方法。
