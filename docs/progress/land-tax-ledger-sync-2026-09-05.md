# 土地税台账同步 - 2026-09-05

## 已实现

- 土地税缴纳现在以统一税务台账的未缴金额为准，同时兼容旧存档中的 `LandClaim.taxOwed` 镜像。
- 土地税单在土地所有者执行缴税时自动完成声明，再进入统一支付流程；土地税属于系统评估税，不要求玩家重复提交所得申报。
- `/land redeem` 赎回处置土地时也读取统一税务台账，避免镜像字段为零导致欠税土地被错误赎回。
- 缴税完成后继续回写土地镜像字段，保持地图和土地界面的快速显示。
- 税务局统一支付入口现在对土地持有税执行与 `/land paytax` 相同的自动声明规则。

## 现实逻辑

土地持有税通常由税务机关按评估价值计算并出具应缴金额，与企业或个人经营所得税的主动申报不同。领域逻辑因此区分“统一台账的法定应付金额”和土地记录中的显示镜像。
