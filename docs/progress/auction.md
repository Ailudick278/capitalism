# 拍卖系统开发进度

最后更新：2026-09-06

## 已实现功能

- 支持拍卖挂牌、竞价、最高价维护、成交、流拍、撤回和网络交互。
- 拍卖物品、竞价款和结算记录使用持久化数据保存，并以唯一拍卖 ID 关联。
- 支持土地拍卖入口，以及普通商品拍卖的结束时间、保证金托管和竞价退款。
- 拍卖结束、流拍、撤回和异常恢复使用结算账本，避免重启造成重复付款、重复退款或托管物品丢失。
- 挂牌和竞价阶段已加入金额溢出、非法记录和无效参与方校验。

## 存在的问题

- 拍卖状态机、保证金、自动延时、违约和争议期规则仍未完全统一。
- 土地拍卖与普通商品拍卖的成交、过户和税费差异仍需进一步抽象。
- `SavedData` 之间没有跨文件原子事务，极端崩溃时仍存在窄的一致性窗口。

## 后续方向

1. 完善挂牌、竞价、结束、流拍、撤回、成交和违约状态机。
2. 抽象统一的托管、退款、成交交割和审计接口。
3. 将土地转让、欠税清偿、成交款分配和产权变更纳入统一结算凭证。
4. 扩展可拍卖资产接口，为企业、库存和证券拍卖预留能力。
