# 拍卖系统开发进度

## 已实现功能

- 支持物品挂牌、竞价、撤回和到期结算。
- 竞价资金进入托管，卖方离线时通过邮箱收款。
- 被抬价竞价者的退款使用“拍卖 ID—原竞价者—原竞价金额”的持久化凭证，在线与离线到账都可安全重试。
- 结算记录具备幂等标记，避免重复发放。
- 钱包引用支付现在具备金额与币种校验的幂等重试基础，可供竞价等前置扣款流程接入。

## 存在的问题

- 缺少统一合同、争议和拍卖失败的违约处理。
- 价格发现仍局限于单次拍卖，缺少历史统计。
- 竞价目前仍是“扣款后写竞价记录”，尚未把竞价意图、付款和拍卖状态纳入统一待处理事务日志。

## 后续方向

1. 接入统一合同状态和交易凭证。
2. 增加拍卖历史、估值和市场信息展示。
3. 增加保证金、恶意竞价和争议处理。
