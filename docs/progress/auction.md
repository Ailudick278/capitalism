# 拍卖系统开发进度

最后更新：2026-09-05

## 已实现功能

- 拍卖作为独立系统维护拍卖对象、拍卖市场和持久化数据。
- 支持挂牌、竞价、最高价维护、成交和相关网络消息基础结构。
- 土地系统已经具备土地拍卖数据入口，可为区块转让提供基础。
- 拍卖相关方可通过命令和界面参与操作。

## 当前边界与待处理问题

- 拍卖时间、保证金、自动延时、流拍、撤拍和违约规则仍需统一。
- 土地拍卖与普通物品/资产拍卖的差异化规则还可以进一步明确。
- 成交后的付款、过户、税费和失败回滚需要更强的事务保障。

## 后续开发方向

1. 完善拍卖生命周期和状态机。
2. 增加保证金、自动扣款、流拍、撤拍、违约和黑名单规则。
3. 将土地拍卖与土地所有权转移、土地转让税正式打通。
4. 抽象可拍卖资产接口，为未来扩展企业、库存和证券拍卖做准备。
