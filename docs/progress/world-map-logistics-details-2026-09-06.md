# 世界地图物流节点详情 - 2026-09-06

## 已实现

- 选中或悬停已探索区块时，详情面板现在会显示该区块是否存在物流设施。
- 如果存在，会显示设施标识：`logistics_center`、`transfer_station` 或 `port`。
- 查询使用地图已经同步到客户端的节点数据，不新增全图扫描，也不改变物流节点的容量、区域和运输结算逻辑。

## 设计依据

物流设施在现实中不仅是地图上的位置标记，还承担仓储、转运或港口装卸等不同职能。把设施类型放入区块详情，可以让玩家在地图上区分“节点存在”和“节点用途”，为后续路线、运力和运输成本展示留下稳定入口。

## 后续方向

- 将内部标识替换为本地化名称，并在详情中补充当前区域的运力与风险摘要。
- 为历史存档中已经放置、但没有被新节点登记器记录的设施提供安全的修复/重建入口。
